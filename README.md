# TopsterTube

유튜브 링크로 재생 가능한 음악 탑스터를 만드는 작은 도구입니다.

- `topstertube-extension`: YouTube/YouTube Music을 들으면서 곡과 현재 재생 시각을 모으는 Chrome 확장 프로그램
- `topstertube`: YouTube 플레이리스트를 Topster 링크로 변환하고, 공유 링크를 동적 Topster로 보여주고 재생하는 Next.js 웹앱

## 기능

- 2x2, 3x3, 4x4, 5x5, Classic 42 레이아웃 지원
- YouTube/YouTube Music 플레이리스트 URL로 웹에서 바로 Topster 생성
- Chrome 확장 프로그램에서는 현재 YouTube 탭의 영상 ID와 재생 시각 저장
- 웹 편집기에서 영상 링크 일괄 추가, 위/아래 버튼으로 순서 변경, 시작 시간 편집, 삭제/실행 취소
- 브라우저 자동 저장과 초안 복원
- 공유 링크, 이미지 링크, `<a><img></a>` HTML, PNG 다운로드, 미리보기 출력
- `d=` compact payload로 기존 `link1/link2...` 방식보다 짧은 URL 생성
- `/s/16자리코드` 영구 단축 주소: NFC 기록용 URL 길이 표시, 원본 링크 대체 경로
- 모바일 터치 컨트롤, 이전/다음 곡, 전체 반복, 탐색, 같은 탭의 재생 위치 복원, Media Session 지원
- 재생 불가 영상 스킵, autoplay 차단 안내, 장시간 buffering 복구 등 재생 안정성 보강
- `/help` 설명 페이지와 `/privacy` 개인정보 처리 안내 제공

웹 플레이리스트 가져오기는 각 곡을 처음부터 재생합니다. 시작 구간은 웹 편집기에서 초 단위로 수정하거나 `?t=1m30s`가 붙은 영상 링크로 추가할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

웹앱은 `http://localhost:3000`에서 확인할 수 있습니다.

## URL 구조

새로 생성되는 공유 링크는 `?d=v1:...` 형식을 사용합니다. 웹앱과 이미지 API는 이전 `?link1=...&link2=...` 링크도 계속 읽을 수 있습니다.

## 단축 주소 저장소

Vercel 프로젝트에 **private Vercel Blob** 저장소를 연결합니다. 연결 시 생성되는 `BLOB_READ_WRITE_TOKEN`은 서버 전용이며 Git이나 클라이언트에 넣지 않습니다. 로컬 개발에서 단축 주소를 테스트하려면 해당 프로젝트의 개발 환경 변수를 `.env.local`에 설정하세요. 저장소가 없으면 API는 503을 반환하고 원본 공유 링크는 계속 사용할 수 있습니다.

`POST /api/shorten`에 `{ "payload": "v1:g3x3:..." }`를 보내면 `{ "path": "/s/..." }`를 반환합니다. 유효한 탑스터만 저장하며 외부 URL 리다이렉트는 지원하지 않습니다. 96비트 SHA-256 접두사로 같은 데이터의 중복 저장을 방지하고, 기존 레코드는 덮어쓰지 않습니다. 충돌 시 저장을 거부합니다. `/s/[code]`는 저장된 데이터를 서버에서 읽어 짧은 주소 그대로 재생 화면을 제공합니다. 만료 없는 고정 사본이며 수정본은 새 링크를 생성합니다. 저장소를 삭제하면 링크도 사용할 수 없으므로 유지해야 합니다.

요청 본문은 4KB, 데이터는 최대 100곡/3KB, 시작 시간은 최대 86400초입니다. Origin 검사 및 인스턴스당 IP별 분당 20회 burst 제한이 있습니다. 이 메모리 제한은 전역 쿼터가 아니므로 트래픽이 커지면 Vercel Firewall 또는 공유 저장소 기반 제한을 추가하세요. 링크는 공개 공유용이며 인증 수단이 아닙니다. 삭제 요청은 운영자가 Blob의 `links/<code>.json`을 삭제하여 처리합니다(캐시 반영에는 시간이 걸릴 수 있습니다).

NFC 기록 앱에서 URL 레코드로 단축 주소를 기록하세요. UI 바이트 수는 URL 텍스트 크기이며 NDEF 레코드 오버헤드는 포함하지 않습니다. 실제 태그 기록과 읽기는 NFC 기기에서 확인해야 합니다.

## 재생 범위

YouTube 공식 iframe 플레이어를 사용하며 오디오 추출·오프라인 저장·숨겨진 강제 백그라운드 재생은 제공하지 않습니다. 작은 표지에서는 최소 200px 플레이어를 별도 표시합니다. Media Session은 지원 브라우저에서 재생 제어를 제공하며 화면 잠금/앱 전환 후 재생은 OS·브라우저·YouTube의 정책에 따라 중단될 수 있습니다. 탭 복귀 시 기존 플레이어를 유지하며 재로드 시 저장된 위치를 사용자가 눌러 이어 들을 수 있습니다.
